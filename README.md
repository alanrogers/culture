# Does biology constrain culture?

This repo contains the sources for my 1988 article "Does biology
constrain culture?", which was published in *American
Anthropologist*. The original LaTeX code is in `main.tex`. I lost the
original figure, so I made a new version in PicTeX, which is in
`figcult.tex`. File `additive.email` contains email between me and
Steve Gaulin about what the model would have looked like if I had made
the costs additive instead of multiplicative.
